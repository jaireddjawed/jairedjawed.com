## Writing a post

Add a Markdown file to `content/blog/`. The file name becomes the URL, so
`my-first-post.md` is published at `/blog/my-first-post`.

Each post starts with a few lines of front matter:

```md
---
title: "My first post"
date: 2026-10-09
summary: "One sentence shown on the blog index and in link previews."
draft: true
---
```

Set `draft: true` to keep a post out of the site until it is ready.
